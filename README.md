# Labels over Layers: a causal, label-efficient and edge-measured benchmark for UAV flight fault detection

Code and results for the paper by Phan Anh Minh and Pham Thanh Tri (FPT University), *"Labels over Layers: A Causal, Label-Efficient and Edge-Measured
Benchmark for UAV Flight Fault Detection"*.

The benchmark scores every time step of a flight from past samples only, splits data by independent flight
groups, varies the share of labelled training flights (5%, 20%, 100%), and measures per-step latency and memory
of 13 detectors on a Raspberry Pi 5.

| Family | Detectors |
|---|---|
| Training-free | MovingVar, SqDiff |
| Unsupervised | PCA, Isolation Forest, HBOS (on window statistics), USAD, FITS |
| TSFM zero-shot | TSPulse (forecasting head) |
| Supervised | LightGBM, ExtraTrees (on window statistics), CNN, TCN, LSTM |

## Repository layout

```
uavbench/   prep.py (logs -> 10 Hz parquet), bench.py (splits, budgets, windows, metrics), methods.py (13 detectors)
tools/      prepare_{alfa,rflymad,uavsead}.py, run_bench.py, make_tables.py, edge_export.py, edge_bench.py
scripts/    reproduce_main.sh, reproduce_ablation.sh, edge_pi5_queue.sh
results/    records/ (one JSON per dataset/detector/fold/budget), edge_pi5/ (Raspberry Pi 5 measurements),
            summary/, tables/, figures/ (regenerated by tools/make_tables.py)
```

## Installation

Python 3.12, CUDA optional (networks train on GPU when available).

```bash
python -m venv venv && . venv/bin/activate
pip install -r requirements.txt
pip install --no-deps TSB_AD==1.5      # its metadata pins numpy<2; only the VUS metric code is used
```

## Data

| Dataset | Source | Preparation |
|---|---|---|
| RflyMAD (real flights) | Kaggle `xianglile/rflymad` (Real-Motor, Real-Sensors, Real-No_Fault) | `python tools/prepare_rflymad.py --src <dir>` |
| UAV-SEAD | Hugging Face `aykutkabaoglu/uav-flight-anomaly-dataset` (downloaded by the script) | `python tools/prepare_uavsead.py` |
| ALFA | `processed.zip` from https://doi.org/10.1184/R1/12707963 | `python tools/prepare_alfa.py --src <processed dir>` |

Processed flights go to `data/processed/<dataset>/` (override with `UAVBENCH_DATA`). The datasets are not
redistributed here; RflyMAD is for non-commercial use.

## Reproducing the paper

```bash
bash scripts/reproduce_main.sh        # Table 4: 13 detectors x 3 datasets x label budgets
bash scripts/reproduce_ablation.sh    # Table 3: channel set, normal-only training, window, 50 Hz, ALFA channels
python tools/make_tables.py           # tables and Fig. 1 from results/records and results/edge_pi5
```

`results/` already contains the records behind the paper, so `make_tables.py` regenerates every table and the
figure without re-running anything. `run_bench.py` skips records that exist; delete or redirect `--out` to
re-run. Main runs take about 6 hours on one RTX 3060 and a 30-thread CPU.

### Raspberry Pi 5

```bash
python tools/edge_bench.py export --ds rflymad --out edge/pkg       # on the training machine
rsync -a edge/pkg tools/edge_bench.py scripts/edge_pi5_queue.sh pi:bench/
ssh pi 'cd bench && ./edge_pi5_queue.sh'                            # numpy, scikit-learn, lightgbm, onnxruntime, torch (CPU)
```

Each run streams one test flight sample by sample and first checks that the streamed scores match the offline
scores.

## Protocol in brief

- 10 Hz zero-order hold; score at time t from the window [t-31, t]; only in-air samples are scored.
- Channels standardised with training statistics; site-dependent heading and horizontal position removed.
- Grouped 5-fold CV stratified by fault type (3 folds for UAV-SEAD): groups are flights (RflyMAD), recording
  sessions (UAV-SEAD) and overlapping/same-bag sequences (ALFA, 24 groups).
- ALFA throttle and servo-output channels carry the injected command and are removed from set F (kept in FA).
- Label budget = share of labelled training flights, nested, applied to validation as well.
- VUS-PR (TSB-AD implementation, 1 s buffer) on concatenated test flights; no point adjustment. Operating
  thresholds at 0.1% and 1% FPR on validation, excluding +-2 s around fault intervals.

## Notation

| Paper | Code |
|---|---|
| channel sets F, K, FA | `--chset F`, `K`, `FA` |
| label budget 5% / 20% / 100% | `--budgets 0.05 0.2 1.0`, records `s<fold>_b<budget>.json` |
| log-level split of UAV-SEAD | `--uavsead-group log` |
| normal-only training of unsupervised detectors | `--unsup-normal` |
